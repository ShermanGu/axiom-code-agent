Axiom ZIP 替换后操作（PowerShell）

先保留原来的 .axiom/config.toml；它包含模型、API Key、base_url 和 no_proxy 配置。

py -3.14 -m venv .venv
创建独立的 Python 环境；如果 .venv 已存在，可以跳过。

.\.venv\Scripts\Activate.ps1
激活虚拟环境，避免和电脑里的 Python 组件冲突。

python -m pip install --upgrade --force-reinstall .
按照当前 ZIP 的代码和依赖，完整重新安装 Axiom。

axiom doctor
检查配置、依赖、API Key 和运行环境是否正常。

axiom tui
启动 Axiom 的终端界面。
