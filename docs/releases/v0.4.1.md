# Axiom v0.4.1 — P0-1 hardening

Status: In review

Priority track: P0-1

## Outcome

The deterministic evaluation foundation remains green while Windows users can start stdio MCP
servers from the TUI and inspect large Skill catalogs without dumping every path by default.

## Scope

- [x] Use a stable diagnostic file handle when the TUI has replaced `sys.stderr`.
- [x] Treat an omitted MCP `args` field and `args = []` identically.
- [x] Add a real stdio subprocess regression test with a redirected current error stream.
- [x] Keep `axiom skills` backward compatible while making its default output concise.
- [x] Add `axiom skills list`, `axiom skills search QUERY`, and `axiom skills show SKILL_NAME`.
- [x] Align the README and roadmap with the completed P0-1 boundary.

## Acceptance

- [ ] Unit tests pass on Ubuntu and Windows with Python 3.11 and 3.14.
- [x] Ruff and Mypy pass locally.
- [x] The deterministic core evaluation reports 8/8 passed locally.
- [x] The built wheel reports Axiom 0.4.1 and contains the packaged evaluation suite.

## Deferred

- Live-provider quality benchmarks remain a later, credentialed evaluation track.
- Richer Skill filtering and machine-readable CLI output can be added when a concrete consumer
  requires them.
